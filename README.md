# CT 3D Simulator

## Structure
- `index.html`: main entry point
- `assets/css/ct-simulator.css`: stylesheet
- `assets/js/core/state.js`: app state and descriptions
- `assets/js/core/main.js`: scene build, UI wiring, animation loop
- `docs/`: specifications and related documents

## Run
Open `index.html` in a browser.

## Notes
- Legacy files (`onefile.html`, `ct-simulator.html`) are kept for compatibility.
- Main maintained entry is `index.html`.
