# CT 3D Simulator 要求仕様書

## 1. 背景と目的
本シミュレータは、CT操作用コンソールアプリに対し、寝台・ガントリ・インジェクタ等のHWをシミュレータ部として提供する。  
本アプリのUIはHWシミュレータ操作用の実装であり、実コンソール接続時は置き換え可能な構成を前提とする。

## 2. スコープ
- Webブラウザで動作するCTシミュレータ
- HWシミュレータ部
- 3D空間表示
- UI部（簡易コンソール）
- コンソールアプリ連携I/F
- **仮想カメラ映像配信機能（RTSP / HTTP）**

## 3. 機能要件

### 3.1 HWシミュレータ部
- **ガントリ**: スキャン中状態、回転速度、検出器列数、X線表示制御
- **寝台**: Y/Z軸移動制御
- **インジェクタ**: A/B残量・注入率制御
- **共通**: 外部コマンドによる操作と応答

### 3.2 3D空間表示
- 各HWの配置表示
- 検査室/操作室要素の表示
- 人体モデル表示ON/OFF
- カメラ視点切替、フォーカス移動
- ガントリ透過表示切替

### 3.3 UI部
- HW状態モニタ
- 簡易コンソール実装（スキャン開始/停止、バッチキュー編集、シーケンス実行/停止）
- HW設定（Detector Rows、Couch Y/Z、Injector A/B）
- 3D表示設定（視点、表示、フォーカス）

### 3.4 コンソールアプリ連携
- 外部から仮想HWを通信制御可能
- UI操作と外部操作を同一コマンド経路で処理
- 状態変化に対し結果を返却

### 3.5 仮想カメラ映像配信機能
- **仮想カメラ制御**: 3Dシミュレータ空間内に撮影用仮想カメラを設置し、位置・視点・解像度・フレームレートを制御可能とする。
- **映像エンコード**: 3D空間描画フレームを **H.264** または **MJPEG** フォーマットにエンコードする。
- **ストリーミング配信**: 外部モニタやコンソールアプリに対し、**RTSP** または **HTTP** (MJPEG Stream / HLS / WebRTC 等) でリアルタイム映像を配信する。
- **配信制御**: 外部コマンドI/FおよびUIから、配信の開始/停止、配信URL取得、ストリーム画質設定を行えるようにする。

## 4. 非機能要件
- **拡張性**: 機種差分をプロファイル/モデル差し替えで対応
- **保守性**: UIから直接HW状態を変更しない
- **可読性**: レイヤ分離されたディレクトリ構成
- **互換性**: モダンブラウザ動作
- **リアルタイム性**: 映像配信の低遅延化（低遅延ストリーミング対応）
- **文字コード**: UTF-8（BOMなし）/ LF

## 5. 受け入れ基準
1. 3D表示が正常に描画される
2. UI操作でHW状態が変化する
3. バッチシーケンスが実行できる
4. 外部I/Fで `gantry/couch/injector/simulator` を制御できる
5. 状態モニタとコマンドログへ反映される
6. **仮想カメラ映像が指定されたフォーマット（H.264 / MJPEG）およびプロトコル（RTSP / HTTP）で配信・閲覧できる**
