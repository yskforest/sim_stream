# CT 3D Simulator 要求仕様書

## 1. 背景と目的
本シミュレータは、CT操作用コンソールアプリに対し、寝台・ガントリ・インジェクタ等のHWをシミュレータ部として提供する。  
本アプリのUIはHWシミュレータ操作用の実装であり、実コンソール接続時は置き換え可能な構成を前提とする。

## 2. スコープ
- Webブラウザで動作するCTシミュレータ
- HWシミュレータ部
- 3D空間表示およびカメラ視点制御（Orbit / FPS Walkthrough）
- UI部（簡易コンソール・モニタ・設定パネル）
- コンソールアプリ連携I/F（`window.CTExternalGateway`）
- **仮想カメラ映像配信機能（RTSP / HTTP MJPEG）**
- **OpenCV 魚眼レンズカメラ歪曲シミュレーション機能**
- **3Dモデルレジストリ＆9-DOFトランスフォーム管理機能**
- **外部設定ファイル（`config.json`）による環境・カメラ・モデル一括構成**
- **画面静止時の描画負荷最適化（Eco Mode レンダリング）**

## 3. 機能要件

### 3.1 HWシミュレータ部
- **ガントリ**: スキャン中状態、回転速度、検出器列数、X線表示制御
- **寝台**: Y/Z軸移動制御（上下・前後）
- **インジェクタ**: A/B残量・注入率制御
- **共通**: 外部コマンドによる操作と応答

### 3.2 3D空間表示および視点制御
- 各HWの配置表示（ガントリ、寝台、インジェクタ、サーバーラック、操作室、検査室）
- 人体モデル（GLB）表示ON/OFF、モデル選択、9-DOF（Pos XYZ, Rot XYZ, Scale XYZ）トランスフォーム調整
- **OrbitControls 視点操作**: 回転・パン・ズーム・プリセット視点切替
- **FPS Walkthrough（一人称視点移動）**: WASD移動、マウスドラッグ視線回転、Shift高速移動、Q/E上下移動、画面下部HUDガイド表示
- ガントリ透過表示切替

### 3.3 UI部
- HW状態モニタ（ガントリ、寝台、インジェクタ、スキャン状態、直近結果）
- 簡易コンソール実装（スキャン開始/停止、バッチキュー編集、シーケンス実行/停止）
- HW設定（Detector Rows、Couch Y/Z、Injector A/B）
- 3D表示設定（視点切替、表示要素、フォーカス、患者GLBモデル選択および9-DOF移動/回転/拡大縮小スライダー）
- **カメラレンズ歪曲設定UI**: 魚眼レンズトグル、レンズプリセット選択、パラメータスライダー（$k_1, k_2, k_3, k_4, f_x, f_y, c_x, c_y$, Zoom）およびリセット機能
- **仮想カメラ配信設定UI**: 配信開始/停止、コーデック/プロトコル選択、ストリームURL表示・診断リンク
- **FPS Walkthrough HUD**: 操作キーガイドおよび動作状態バッジ

### 3.4 コンソールアプリ連携
- 外部から仮想HW・カメラ・モデルを通信制御可能（`window.CTExternalGateway`）
- UI操作と外部操作を同一コマンド経路（`CTCommandBus`）で処理
- 状態変化に対し結果を返却（同期応答および `subscribe` によるリアルタイムイベント購読）

### 3.5 仮想カメラ映像配信機能
- **仮想カメラ制御**: 3Dシミュレータ空間内に撮影用仮想カメラを設置し、位置・視点・解像度・フレームレートを制御可能とする。
- **映像エンコード**: 3D空間描画フレームを **H.264** または **MJPEG** フォーマットにエンコードする。
- **ストリーミング配信**: 外部モニタやコンソールアプリに対し、**RTSP** または **HTTP** (MJPEG Stream) でリアルタイム映像を配信する。
- **配信制御**: 外部コマンドI/FおよびUIから、配信の開始/停止、配信URL取得、ストリーム画質設定を行えるようにする。

### 3.6 OpenCV 魚眼レンズカメラ歪曲シミュレーション機能
- **歪曲モデル**: OpenCV `cv::fisheye`（Kannala-Brandt 多項式モデル: $\theta_d = \theta(1 + k_1\theta^2 + k_2\theta^4 + k_3\theta^6 + k_4\theta^8)$）に基づく逆歪曲リアルタイムシェーダー演算。
- **色空間補正**: 線形色空間から sRGB ガンマ 2.2 変換（`pow(color.rgb, vec3(1.0 / 2.2))`）を適用し、明るさ・発色を正確に再現。
- **レンズプリセット**: Standard Fisheye, Wide Action Cam, Ultra-Wide, Pincushion などのプリセットおよびカスタム調整に対応。
- **ストリーム連携**: メイン画面および MJPEG/RTSP 配信映像の両方にレンズ歪曲効果を同時に適用。

### 3.7 設定管理（Configuration Service）
- **外部JSON設定**: `config.json` により、カメラ解像度・FOV・歪曲係数、ネットワークポート、グラフィック品質、初期患者モデル、配置モデル一覧を外部から定義可能。
- **動的モデル登録**: 3Dモデルレジストリを介し、任意のGLBファイルや画像看板アセットをランタイムで追加・配置。

## 4. 非機能要件
- **拡張性**: 機種差分をプロファイル/モデル差し替えで対応
- **保守性**: UIから直接HW状態を変更せず、CommandBus/Store経由で一元管理
- **可読性**: レイヤ分離されたディレクトリ構成
- **互換性**: モダンブラウザ動作（ES Modules / WebGL）
- **リアルタイム性**: 映像配信の低遅延化および60fpsリアルタイム歪曲シェーダーレンダリング
- **パフォーマンス（Eco Mode）**: アニメーションやユーザー操作がない静止時は再描画ループをスキップし、CPU/GPUリソース消費を最小化
- **文字コード / 改行**: UTF-8（BOMなし）/ LF

## 5. 受け入れ基準
1. 3D空間（ガントリ・寝台・検査室等）が正常に描画される
2. UI操作およびFPSウォークスルー操作（WASD/ドラッグ）で視点やHW状態が滑らかに変化する
3. バッチシーケンスが実行できる
4. 外部I/F（`window.CTExternalGateway`）で `gantry/couch/injector/simulator/camera` を制御でき、9-DOFモデル操作や歪曲パラメータ更新が正しく適用される
5. 状態モニタとコマンドログへリアルタイムに反映される
6. 仮想カメラ映像が指定されたフォーマット（H.264 / MJPEG）およびプロトコル（RTSP / HTTP）で配信・閲覧できる
7. OpenCV 魚眼レンズ歪曲設定が画面および動画配信ストリームへ正確な色調・明るさで反映される
8. `config.json` の設定値（カメラ・モデル・ネットワーク）が起動時に正しく反映される
9. 画面静止時に余計なレンダリング計算がスキップされ、低負荷で動作する
10. `scripts/verify-external-interface.js` による外部I/Fの自動検証テストがすべて合格する
