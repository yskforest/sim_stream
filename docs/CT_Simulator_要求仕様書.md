# CT 3D Simulator 要求仕様書

## 1. 目的
本シミュレータは、CT検査室の主要ハードウェア（ガントリ、寝台、インジェクタ）を3D空間上で再現し、UI操作および外部コマンドで制御できる検証基盤を提供する。
加えて、CT操作用コンソールアプリに対し、実機代替のHWシミュレータ部を提供し、開発・試験・教育を一貫して支援する。

## 2. スコープ
- Webブラウザで動作する単体シミュレータ
- HWシミュレータ部（ガントリ、寝台、インジェクタ）
- 3D可視化（検査室、人体モデル、カメラ視点）
- UI部（簡易コンソール機能）
- 外部コンソールアプリ連携I/F

## 3. 想定利用者
- コンソールアプリ開発者
- システム検証担当
- 教育・トレーニング担当

## 4. 機能要件

### 4.1 HWシミュレータ部
1. ガントリ
- 回転速度、スキャン状態、X線ビーム表示、検出器列数を制御可能であること。
2. 寝台
- 高さ（Y）と挿入位置（Z）を制御可能であること。
3. インジェクタ
- Contrast(A)とSaline(B)の注入進捗を制御可能であること。
4. 共通
- 外部コマンドで各HWを個別制御できること。
- 実行結果を状態として応答できること。

### 4.2 3D空間表示
1. 各HWと検査室構成要素を3D配置すること。
2. 状態変更が3Dモデルに即時反映されること。
3. 複数カメラ視点（自由視点、操作者視点、患者視点、注目視点）を提供すること。

### 4.3 UI部
1. UIの役割
- HWシミュレータ操作のための標準UIを提供する。
- 実コンソール接続時に置換可能な設計とする（UI依存でHWが停止しない）。
2. 操作カテゴリ
- ビュー制御: カメラ視点選択、フォーカスターゲット選択
- 表示制御: ガントリ透過、X線可視化、患者モデル表示
- ハード制御: 寝台、ガントリ、インジェクタの直接操作
- スキャン運用: スキャン開始/停止、バッチ編集、シーケンス実行/停止
3. UI状態表示
- システム状態（STANDBY/SPINNING/SCANNING）
- 回転速度、検出器列数、寝台位置、インジェクタ残量
4. UI改善方針
- 重要操作を上位に配置し、操作カテゴリを明示すること。
- 実行中に禁止すべき操作をUI上で無効化すること。
- 操作結果を1秒以内に可視反映すること。

### 4.4 コンソールアプリ連携
1. 外部コマンドの受信・解釈・状態応答を行えること。
2. UI経由と外部コマンド経由で同一状態モデルを共有すること。
3. UI未使用時でもHWシミュレータ部が継続動作できること。

## 5. 非機能要件
1. 可読性
- UI層、HWシミュレータ層、3D表示層、連携層を分離すること。
2. 拡張性
- 機種差分（可動域・列数・プロトコル）をプロファイルで切替可能にすること。
3. 保守性
- 操作項目追加時に既存ID/イベント契約を破壊しないこと。
4. 性能
- 通常操作時に体感遅延なく描画・状態更新が行えること。

## 6. 受け入れ基準
1. ガントリ・寝台・インジェクタの各操作が3D表示へ反映される。
2. スキャンシーケンスの追加/削除/実行/停止が可能である。
3. UI表示に文字化けがなく、日本語表示が正常である。
4. 外部コマンドでUI同等の制御が可能である。
